# 2026-react

2026 한입크기로 잘라먹는 타입스크립트

1. 타입스크립트 개론 - 동작 원리
2. 타입스크립트 기본 - 기본, 원시, 리터럴 타입, 배열, 튜플, 객체, 타입 별칭, 인덱스 시그니처, enum, any, unknown, Void, Never
3. 타입스크립트 이해 - 집합, 타입계층도, 객체타입의 호환성, 대수타입, 타입 추론, 타입 단언, 타입 가드, 서로소 유니온 타입
4. 함수와 타입 - 함수타입, 함수타입표현식, 호출시그니처, 함수 타입의 호환성, 함수 오버로딩, 사용자 정의 타입 가드
5. 인터페이스 - 확장, 인터페이스 합치기
6. 클래스 - 접근제어자, 인터페이스와 클래스
7. 제네릭 - 타입 변수 응용, map,foreach 메서드 타입 정하기, 제네릭 인터페이스, 타입 별칭, 클래스, 프로미스와 제네릭
8. 타입 조작 - 인덱스드 엑세스 타입, keyof, 맵드 타입, 템플릿 리터럴 타입
9. 조건부 타입 - 분산적인 조건부 타입, infer- 조건부 타입 내에서 타입 추론
10. 유틸리티 타입 - partial, required, readonly, pick, omit, record, exclude, extract, returntype
11. 리액트와 타입스크립트
